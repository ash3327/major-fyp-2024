# Source Library

Note that the OLD training code are put within the `libs/` folder and the NEW training code are put within the `src/` folder.

## What are the differences?

The older training codes are less compact, but since deleting the old codes would make previous codes break, we would kept them there.

## How is it laid out?

`data/`: stores data loaders from datasets.
`models/`: stores the models.
`trainers/`: stores the training scripts.
`verifiers/`: stores the verification scripts.
`config_loader/`: stores the config loader script.
